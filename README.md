React-Projekt mit Spotify-API-Integration. 
Damit die App Daten abrufen kann, muss zuerst ein Tokenserver gestartet werden.

Repository clonen:

git clone https://github.com/projects-vp/rocky-beach-welle.git

cd rocky-beach-welle

npm install

cd token

node get-token.js

cd ..

npm start

http://localhost:3000
